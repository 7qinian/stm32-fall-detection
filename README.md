# STM32 跌倒检测终端

基于 STM32F103 的智能跌倒检测系统，包含完整的 BootLoader 和 OTA 升级功能。

## 功能特性

- ✅ 基于 MPU6050 的实时姿态检测
- ✅ 五态有限状态机摔倒识别算法（失重→撞击→姿态→静止→确认）
- ✅ 非阻塞式串口环形缓冲区数据接收
- ✅ 双区备份 BootLoader，支持 OTA 固件升级
- ✅ 分层架构设计：驱动层 / 算法层 / 应用层

## 硬件平台

- MCU: STM32F103C8T6
- 传感器: MPU6050 六轴惯性测量单元
- 通信: 预留 UART 接口，可扩展 4G/WiFi 模块
